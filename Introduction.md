# About

This repository provides supplementary notes for **1CV40 Reliability and Quality Engineering** at Eindhoven University of Technology, taught by Claudia Fecarotti and Juseong Lee. It contains notes covering the topics discussed in each lecture.

The aim is to complement the lectures by addressing common questions, clarifying challenging concepts, and providing links to further reading on selected topics. As an **advanced-level bachelor's course**, 1CV40 builds on students' existing knowledge while also offering opportunities for those interested in exploring particular subjects in greater depth. These notes are intended to support both revision of prerequisite knowledge and further independent learning.

# **Site structure**

This site is built using [Jupyter Book](https://jupyterbook.org/en/stable/intro.html), with content written primarily in Markdown. You can download the source file for any page using the option in the upper-right corner. Each page corresponds to a lecture listed on Canvas, although the order may change slightly from year to year as the course evolves.
